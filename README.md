# probe — изолированный runtime-экспериментатор для PE32

Интерактивный REPL для вызова отдельных функций из 32-битных Windows
бинарников (PE32/x86) в изолированной среде с возможностью подменять
внутренние вызовы моками.

## Что решает

- **CTF / crackme**: обход проверок через `set mock check_password --return 1`.
- **Извлечение крипто-примитивов**: `invoke function decrypt [...] --diff 64`
  без запуска всего бинарника.
- **Разведка «что если»**: подставить разные `--return` в моки и
  посмотреть, как меняется поведение функции-валидатора.
- **Юнит-тестирование скомпилированных функций**: вызвать `parse_config`
  из своей DLL без поднятия всего сервиса.

## Что не решает

- Только PE32/x86. x64 не поддерживается.
- Discovery через entry + exports + прямые CALL. Stripped EXE без
  экспортов, где стартовый код идёт через `call [mem]`, найдётся
  только частично.
- Косвенные вызовы (`call eax`, `call [mem]`) не патчатся — мок не встанет.
- SEH (`__try/__except`) внутри функции не работает: ручной маппинг
  + SafeSEH → обработчик не находится в `.sxdata`.
- `float`/`double` через XMM не передаются (только int / pointer / ANSI / wide).
- Функции, создающие свои потоки, не отслеживаются (VEH ловит только
  sandbox-поток).

## Сборка

    rustup target add i686-pc-windows-msvc
    cargo build --target i686-pc-windows-msvc --release

## Базовый workflow

    probe> find function --sort name          # найти экспорты
    probe> get function login                 # карта вызовов
    probe> alloc 64                           # буфер для out-параметра
    probe> poke 0x<addr> "input"              # записать данные
    probe> set mock check_password --return 1 # подменить зависимость
    probe> invoke function login [w"admin" 0x<addr>] --diff 64
    probe> call log                           # история эксперимента

## Границы применимости

Работает:
- PE32 DLL с экспортами (проверено на SysWOW64\version.dll)
- crackme с явными `__declspec(noinline)` / `#[inline(never)]` функциями
- свои небольшие DLL/EXE, где известно, какую функцию вызывать

Не работает:
- SysWOW64 DLL без экспортов нужных функций
- приложения с анти-отладкой, полагающиеся на то, что `main` был вызван
- функции, зависящие от глобального состояния, инициализируемого CRT
